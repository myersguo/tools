CLIsingle page generator

Terminal / CLI介绍页模板生成器

把一段介绍文案和一段终端内容转换成可复制、可下载、可预览的独立单页 HTML。适合 Codex、NTT、ntt-env，以及其他需要终端展示的工具介绍页。

规则文本以 **标题** 开头才会生成 H1；不写标题或使用 **** 均不显示 H1。序号和按钮留空时不会渲染。终端区保留换行，**token** 会高亮。

输入内容

点击生成，或按 Ctrl/⌘ + Enter 快速更新。

选择生成页结构；所有模板都保持单文件、无外部依赖。
需要标题时以 **标题** 开头；直接写正文或使用 **** 开头时不显示标题。正文也支持少量 **加粗**。
Hero / Feature 模板使用；长命令会在生成页终端面板内部横向滚动。
Steps：1 | 标题 |说明 | 命令；Cards：01 | 命令 | 标题 |说明。一行一项，命令内可继续包含 |。
